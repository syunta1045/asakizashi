プライバシーポリシー

最終更新日: 2026年4月29日

endsy（以下「当方」）は、モバイルアプリケーション「朝しるべ」（以下「本アプリ」）における利用者（以下「ユーザー」）の個人情報の取り扱いについて、以下のとおりプライバシーポリシー（以下「本ポリシー」）を定めます。

1. 取得する情報

本アプリは、毎朝のメッセージと振り返り体験のパーソナライズのため、以下の情報を取得します。

1.1 ユーザーが入力する情報

  • ニックネーム
  • 生年月日
  • 生まれた場所（都道府県）
  • 性別（任意）
  • MBTI / 血液型（任意・メッセージのトーン調整用）
  • 起床時間 / 関心テーマ（任意・通知時刻と内容のパーソナライズ用）

1.2 サインイン時に取得する情報（任意）

  • Apple Sign-in / Google Sign-in を利用した場合のみ:
    • メールアドレス
    • 表示名

1.3 自動的に取得する情報

  • アプリの利用状況（画面遷移・タップなど）— サービス改善のため
  • クラッシュレポート — 不具合検出のため
  • アプリのバージョン情報・OS バージョン

2. 利用目的

取得した情報は、以下の目的で利用します。

  • 生年月日にもとづく朝のメッセージと行動メモのパーソナライズ
  • ユーザーへの通知（朝メモ・振り返りリマインダー）
  • ユーザーが登録した「つながり」（家族・推し等）との距離感ヒント表示
  • アプリの不具合修正・品質向上
  • 利用統計の分析

3. 第三者への提供

当方は、以下の場合を除き、ユーザーの個人情報を第三者に提供しません。

  • ユーザーの同意がある場合
  • 法令に基づき開示する義務がある場合

4. 利用する外部サービス

本アプリは以下の外部サービスを利用しており、ユーザー情報の一部が各サービスのプライバシーポリシーに従って処理されます。

サービス用途データ
Supabaseデータベース・認証ニックネーム・生年月日・朝のパーソナル設定・サインイン情報
Google Cloud (Gemini API)メッセージ生成匿名化された内部コードのみ（個人特定情報は送信しない）
Apple Sign-in / Google Sign-in認証（任意）OAuth トークン
RevenueCat課金管理（プレミアム機能）サブスクリプション状態
Sentry不具合検出エラーログ・端末情報
Expo Push Notification Serviceプッシュ通知配信端末トークン

5. データの保存場所

ユーザー情報は、Supabase の Asia-Northeast (Tokyo) リージョンに保存されます。サーバーへの通信は TLS で暗号化されます。

6. データの保持期間

  • アクティブな利用がある間は保持します。
  • アカウント削除を行った場合、サーバー上のデータは速やかに削除されます（最大30日）。
  • ローカル端末の振り返り日記は最大2年間保持されます（端末上のみ）。

7. ユーザーの権利

ユーザーは以下を行うことができます。

  • データの確認・修正: アプリ内「あなた」タブから可能
  • アカウント削除: アプリ内「設定」→「アカウントを削除」
  • 通知の停止: アプリ内「設定」→「通知の設定」または OS の設定から
  • データの開示・訂正・利用停止の請求: 以下のメールアドレスへご連絡ください

8. お子様のプライバシー

本アプリは13歳未満のお子様を対象としていません。13歳未満のお子様の個人情報を取得した場合は、保護者の同意がない限り速やかに削除します。

9. ポリシーの変更

本ポリシーは、必要に応じて改定することがあります。改定後のポリシーは本アプリおよびウェブサイトに掲載した時点で効力を生じます。
