# 朝しるべ App Store スクショ作成

シミュレータの素のスクショに、**朝焼けグラデ背景＋キャプション＋端末フレーム**を付けて、
App Store 正寸（1242×2688px）の見栄えするスクショを書き出すツール。

## 使い方（3ステップ）

### 1. スクショを撮って `images/` に入れる
iOS シミュレータで5枚撮って、この名前で `images/` に置く:

| ファイル名 | 画面 | キャプション |
|---|---|---|
| `01-pace.png` | 今日のペース | 毎朝1分で、今日のペースが決まる |
| `02-memo.png` | 朝メモ / 通知 | 朝メモは、起きて10分後にそっと届く |
| `03-journal.png` | 夜の振り返り | 夜は、気分をひとことだけ |
| `04-calendar.png` | 月間カレンダー | 続けた朝が、カレンダーに積もる |
| `05-relations.png` | つながり | 大切な人との距離も、ここに |

### 2. 一回だけ準備
```bash
cd store-screenshots
npm i -D puppeteer
```

### 3. 書き出し
```bash
node render.mjs
```
→ `out/screenshot-01.png` 〜 `05.png` が出る（各 1242×2688px）。
これを App Store Connect の **6.5インチ枠**に5枚差し替えるだけ。

## カスタマイズ

- **キャプションを変える**: `index.html` の `SLIDES` の `cap` を編集（`\n` で改行）
- **完成イメージを目で確認**: `index.html` をブラウザで開く（Cmd+「−」で縮小すると全体が見える）
- **6.9インチ枠も作りたい**: `index.html` の `--w / --h` を `1290px / 2796px` に変えて再実行

## 補足
- `images/` の中身と `out/` は Git に入れなくてOK（`.gitignore` 済み）
- 端末フレームの色・角丸・グラデの配色は `index.html` の `<style>` で調整できる
